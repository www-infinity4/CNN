# CNN World News

Rolling CNN news channel for the Infinity TV remote.

- Daytime and overnight playback starts from CNN's continuously updated official YouTube uploads playlist rather than a fixed weekly program list.
- 8:00–10:00 PM local time is reserved for an Anthony Bourdain / Parts Unknown archive block using official CNN videos.
- 10:00 PM–midnight returns to CNN prime/current reporting.
- The channel remote first checks the shared `Omni-Control/channels.json` source and falls back to the built-in channel list until that shared repo is available.
- Share progress uses the existing StarQuest local profile keys so the wallet button can show completed StarCoins plus pending 1/10 share credit.
- Social cards use `assets/cnn-world-social.png` at 1200×630.

Video availability remains controlled by CNN/YouTube. The page does not remove or bypass source-player advertising, access restrictions, or publisher controls.
